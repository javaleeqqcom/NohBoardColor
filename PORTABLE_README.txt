NohBoardColor v1.4.4 Windows x64 绿色版
=======================================

使用方法
--------
1. 将压缩包完整解压到任意可写目录，例如桌面或“文档”。
2. 双击 NohBoard.exe 运行，不需要安装，也不需要管理员权限。
3. 请不要只把 NohBoard.exe 单独复制出去；keyboards 文件夹必须与程序放在一起。

默认设置
--------
- 首次启动加载 Normal/us_intl 标准键盘。
- 按键高亮在 1000 ms 内逐渐变暗。
- 双状态符号键默认采用实体键帽式显示。
- Ctrl+Alt+T：切换窗口置顶。
- Ctrl+Alt+O：切换空闲透明与自动隐藏标题栏。

配置与重置
----------
- 设置保存在程序目录旁的 NohBoard.json。
- 分享给其他用户时，可保留该文件以分享相同设置，也可删除它让程序恢复默认设置。
- 如果程序所在目录不可写，设置可能无法保存；建议不要直接放在 Program Files 中。

系统要求
--------
- 64 位 Windows 10 或 Windows 11。
- 本包为自包含版本，无需另外安装 .NET Runtime。
